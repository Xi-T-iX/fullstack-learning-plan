## The concept

The page is a projection of an array — core of modern UI. Keep all examples AEC-flavored: rooms, areas, inventories.

## Annotated example

```
function render(rooms) {
  const ul = document.querySelector("ul");
  ul.innerHTML = "";
  rooms.forEach(r => {
    const li = document.createElement("li");
    li.textContent = r.name + " — " + r.area + " m²";
    ul.appendChild(li);
  });
}
```
