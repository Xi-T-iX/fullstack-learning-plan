## How the session works (90 min)

Device toolbar · media query · fix overflow · retest three widths

## Tool steps (do these in order)

1. DevTools Ctrl+Shift+M.
2. @media (min-width: …) mobile-first.
3. meta viewport in head if missing.

## The concept

**Mobile-first:** base styles for small screens; add complexity at breakpoints. Viewport meta tells mobile browsers not to shrink a desktop layout blindly.

## Annotated example

```
<meta name="viewport" content="width=device-width, initial-scale=1" />

/* css */
@media (min-width: 800px) {
  .grid { flex-wrap: nowrap; }
}
```

## Where beginners go wrong

1. Missing viewport meta.
2. Only testing desktop.
3. Fixed pixel widths on containers.
