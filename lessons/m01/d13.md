# M1-D13 — Docs literacy — MDN HTML elements

## Today's summary

Once this milestone, you practice reading official docs — a career skill.

## What this is & why you need it

Tutorials go stale. Docs are the source of truth. Skimming MDN poorly is still better than only chatting with AI.

## How the session works (90 min)

Open MDN · skim with a purpose · write 3 answers · Ask grades

## Tool steps (do these in order)

1. Browser only for the docs page.
2. learning-log.md for answers.
3. Ask mode to grade — not to fetch the answers first.

## The concept

Official docs list elements, attributes, accessibility notes. You don't memorize the catalog — you learn to **look up** and extract what you need.


## Where beginners go wrong

1. Skimming without writing answers.
2. Asking Cursor to summarize instead of reading.
3. Bookmarking nothing for later.
