## Tool steps (do these in order)

4. Browser → github.com to confirm the file.

## The concept

You type a URL. **DNS** finds the server's address (like looking up a site address). The browser sends an **HTTP request**. The server sends an **HTTP response** (usually HTML). The browser **parses** HTML into a tree and paints pixels. Git **commit** snapshots your files; **push** uploads commits to GitHub.

## Annotated example

```
<!-- index.html -->
<!DOCTYPE html>           <!-- tells the browser: modern HTML -->
<html lang="en">          <!-- root of the document tree -->
  <head>
    <meta charset="UTF-8" />
    <title>Hello</title>  <!-- browser tab label -->
  </head>
  <body>
    <h1>Hello, I'm Kshitij</h1>  <!-- visible content -->
  </body>
</html>
```

## Where beginners go wrong

3. Writing the 5 sentences with jargon you can't explain.
