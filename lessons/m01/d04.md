# M1-D4 — Semantic HTML

## Today's summary

You replace div soup with header/nav/main/footer so tools and humans understand the page.

## What this is & why you need it

Screen readers and search engines read structure. B2B products that ignore this feel amateur and exclude users.

## How the session works (90 min)

Review nesting · lesson · restructure page · image with alt · Ask audit (issues only)

## Tool steps (do these in order)

1. Edit HTML by hand.
2. DevTools Accessibility pane.
3. Ask: audit semantics — do not let Agent apply fixes.

## The concept

**Semantic** tags describe meaning: `header`, `nav`, `main`, `footer`, `section`. A `div` is a generic box — fine when nothing else fits. Images need `alt` text that describes purpose, not "image1".

## Annotated example

```
<header>
  <h1>Kshitij Nashine</h1>
  <nav><a href="#projects">Projects</a></nav>
</header>
<main id="projects">...</main>
<footer>Contact: you@email.com</footer>
```

## Where beginners go wrong

1. Wrapping everything in divs out of habit.
2. Empty alt or alt that repeats the caption uselessly.
3. Multiple h1s competing as the page title.
