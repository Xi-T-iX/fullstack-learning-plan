# M1-D11 — Flexbox I — axes and centering

## Today's summary

## What this is & why you need it

## Tool steps (do these in order)

2. justify-content and align-items.
3. DevTools flex overlay if available.

## The concept

On a flex container, **main axis** direction is row (default) or column. `justify-content` packs along main; `align-items` along cross. Centering a card in the viewport: column or row flex on a full-height parent with both set to center.

## Annotated example

```
body {
  min-height: 100vh;
  display: flex;
  justify-content: center; /* main axis */
  align-items: center;     /* cross axis */
}
```

## Where beginners go wrong

1. Putting display:flex on the child instead of the parent.
2. Confusing justify and align.
3. Using absolute positioning when flex is enough.
