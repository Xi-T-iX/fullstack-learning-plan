# M1-D12 — Flexbox II — wrap and gap

## Today's summary

You lay out three project cards that wrap on small screens.

## What this is & why you need it

Real portfolios are rows of cards. Wrap + gap is the minimum professional layout.

## How the session works (90 min)

Center recall · wrap lesson · three cards · resize window test

## Tool steps (do these in order)

1. flex-wrap: wrap; gap: 1rem;
2. Narrow the browser.
3. No horizontal scrollbar allowed.

## The concept

`flex-wrap: wrap` lets items move to the next line. `gap` spaces items without margin tricks. Card children need a sensible `flex-basis` or width so they wrap predictably.

## Annotated example

```
.grid {
  display: flex;
  flex-wrap: wrap;
  gap: 1rem;
}
.card {
  flex: 1 1 220px; /* grow, shrink, basis */
  border: 1px solid #ccc;
  padding: 1rem;
}
```

## Where beginners go wrong

1. Fixed widths that force overflow on mobile.
2. Margins instead of gap (harder to keep even).
3. Forgetting wrap.
