## The concept

An HTML document is a **tree of elements**. Tags mark the start and end of each element. Nesting must be clean — like a WBS: children close before parents. Headings `h1`–`h6` are outline levels, not font sizes.

## Annotated example

```
<h1>Kshitij</h1>
<p>I build web tools for AEC.</p>
<ul>
  <li>Grasshopper</li>
  <li>Rhino</li>
  <li>ShapeDiver</li>
</ul>
<a href="https://www.shapediver.com" target="_blank" rel="noopener">ShapeDiver</a>
```

## Where beginners go wrong

1. Using headings only to make text bigger.
2. Forgetting closing tags (browsers forgive; bugs hide).
3. Copy-pasting the whole file from Chat instead of typing.
