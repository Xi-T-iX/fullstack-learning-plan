# M1-D18 — GitHub Pages deploy

## Today's summary

You turn the repo into a public URL.

## What this is & why you need it

Live links are proof. Local-only work doesn't count for Milestone 1.

## How the session works (90 min)

Push latest · Settings → Pages · wait · open URL

## Tool steps (do these in order)

1. GitHub repo Settings → Pages.
2. Branch main, folder / root.
3. Wait 1–2 minutes.

## The concept

GitHub Pages hosts static files (HTML/CSS/JS) from your repo. Same mechanism as this learning app.


## Where beginners go wrong

1. Wrong branch.
2. Capitalization in paths breaks on Pages.
3. Caching — hard refresh.
