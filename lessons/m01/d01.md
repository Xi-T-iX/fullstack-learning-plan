## The concept

Think construction: the **browser** is the finished building people walk through. **Node.js** is the site workshop — JavaScript that runs on your machine, not only in a page. **Git** files revisions of the whole project locally. **GitHub** is the cloud copy of that register. **Cursor** is your tutor: Ask mode explains; Agent mode edits files — during Milestone 1 you stay in Ask for learning.


## Where beginners go wrong

1. Treating Git and GitHub as the same thing.
2. Installing but never running `node -v` / `git --version`.
3. Leaving Tab autocomplete on so the editor types your exercises for you.
