# M1-D9 — CSS selectors and text

## Today's summary

You attach a stylesheet and control type and color without breaking HTML structure.

## What this is & why you need it

HTML is structure; CSS is finishes. Separating them lets you restyle without rebuilding the frame.

## How the session works (90 min)

Link CSS file · selectors · style portfolio text · verify unlink breaks styles

## Tool steps (do these in order)

1. Create styles.css.
2. Add <link rel="stylesheet" href="styles.css"> in head.
3. Edit CSS, refresh browser.

## The concept

A **selector** targets elements (`h1`, `.card`, `#main`). Properties assign values (`color`, `font-size`, `margin`). Prefer classes for reusable patterns.

## Annotated example

```
/* styles.css */
body {
  font-family: system-ui, sans-serif; /* readable default */
  line-height: 1.5;
  color: #1a1a1a;
}
h1 {
  font-size: 2rem;
  letter-spacing: -0.02em;
}
a {
  color: #0f766e; /* teal accent — same family as your learning app */
}
```

## Where beginners go wrong

1. Inline styles everywhere (hard to reuse).
2. Styling with h1 for size instead of a class when needed.
3. Wrong path in href so CSS never loads.
